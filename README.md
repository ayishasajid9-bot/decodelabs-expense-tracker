# Expense Tracker

## Description

A simple command-line Expense Tracker built with Python.

The program allows users to enter multiple expenses and calculates the total amount spent.

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the Python file.
5. Enter your expenses when prompted.

## Python Concepts Used

- Variables
- User input
- Float numbers
- While loops
- If/elif conditions
- Arithmetic operations
- Break
